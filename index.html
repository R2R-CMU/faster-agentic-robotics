Abstract

Robot code agents can already reuse programs and run local checks without another model call. Does a separate supervisor still make them faster at the same independently measured performance? We test Jev as a supervisor for two decisions, skill reuse and reasoning effort, with outcome/recovery supervision as a later stage. Elapsed time, including failed runs, is the primary measure; tokens and API cost are secondary.

Method

The supervisor proposes which library skill to reuse and how much reasoning to spend. Common code enforces the rules, and a disabled gate falls back to the native planner.

Native vs. Supervised

Each pair runs the same task from the same scene. Clocks show failure-inclusive elapsed time.
