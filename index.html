Method

A coding agent must program a robot for a new task, such as building a six-cup pyramid. We let it start from code written for an earlier task, such as building a three-cup pyramid, instead of from scratch.

Physical Transfer

We give a fresh agent each new task and start it either from scratch (baseline) or from earlier task code (ours).

Agent time excludes robot execution and operator waits; tokens include cache. Values are means over seeds. Videos play at 4×; click to enlarge.
